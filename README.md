# Nisi Greek Taverna

Public one-page site for Nisi Greek Taverna, 1455 Lakeshore Road, Burlington.

**Client preview (does not expire):** https://tylern7.github.io/nisi-greek-taverna/

This repository is public. GitHub Pages serves the site from the root of `main`.

## What’s in here

- `index.html`, `css/`, `js/`, `photos/` — the site a host can upload
- `source/` — the page component, menu data, and styles
- `client-approval/` — watermarked full-page desktop shot
- `README.txt` — notes for whoever uploads this to a normal web host

OpenTable, Uber Eats, Instagram, and TikTok links point at the restaurant’s existing accounts. Parties of 13 or more still continue to the current group-booking page.
